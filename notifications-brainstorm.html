What deserves the lock screen?

iOS home-screen web apps can send real push notifications. That is a scarce, easy-to-ruin privilege. The inbox can be chatty. The phone should only speak when something changes dinner, the kitchen, or a guest’s plan.

Flip any pick — recommended defaults are already set.

iOS 16.4+ PWA Add to Home Screen required Hosts first, guests via SMS/email Sep 1, 2026

Constraint

Two layers, not one firehose

  • Push for time-sensitive or action-needed moments, even if plated. is closed.
  • Inbox for the existing activity feed — already mocked at /app/inbox.
  • Digest when many small events (RSVPs) would otherwise tap the phone every two minutes.
  • SMS / email for guests who never install the app. Invites already go this way — don’t double-ping.

Permission has to come from a tap, after the user has a party worth caring about — not on first login. Guests RSVPing from an invite link have no Web Push identity unless they create an account and install.
